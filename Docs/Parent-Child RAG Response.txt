5. The network was trained on two NVIDIA GTX 580 3GB GPUs, and the training took between five and six days.
6. The authors chose ReLUs because they are non-saturating nonlinearities that train several times faster than saturating nonlinearities like tanh. Specifically, a four-layer convolutional neural network with ReLUs reaches a 25% training error rate on CIFAR-10 six times faster than an equivalent network with tanh neurons.
7. The two GPUs communicate only at certain layers. They are able to read from and write to one another’s memory directly, without going through host machine memory. For example, kernels in layer 3 take input from all kernel maps in layer 2 (across GPUs), while kernels in layer 4 take input only from kernel maps in layer 3 that reside on the same GPU.

k = 2
n = 5

β = 0.75
9. Overlapping pooling is defined as a pooling layer consisting of a grid of pooling units spaced s pixels apart, each summarizing a neighborhood of size z×z centered at the pooling unit’s location; when s < z, adjacent pooling neighborhoods overlap (whereas s = z gives traditional non-overlapping local pooling). The network uses s = 2 and z = 3.
10. The first convolutional layer filters the 224×224×3 input image with 96 kernels of size 11×11×3 with a stride of 4 pixels.
11. The first, second, and fifth convolutional layers are followed by max-pooling layers. Specifically, response-normalization layers follow the first and second convolutional layers, and max-pooling layers follow both those response-normalization layers as well as the fifth convolutional layer.
12. The fully-connected layers have 4096 neurons each.
13. The first form of data augmentation consists of generating image translations and horizontal reflections by extracting random 224×224 patches (and their horizontal reflections). At test time, the context references the use of ten patches ("on the ten patches").
14. The second form of data augmentation works by altering the intensities of the RGB channels in training images. Specifically, PCA is performed on the set of RGB pixel values throughout the ImageNet training set, and multiples of the found principal components are added to each training image.
15. Dropout is applied in the first two fully-connected layers, with a dropout probability of 0.5 (the output of each hidden neuron is set to zero with probability 0.5).
16. Batch size: 128
Momentum: 0.9
Weight decay: 0.0005
17. Weights were initialized from a zero-mean Gaussian distribution with standard deviation 0.01. Neuron biases were initialized with the constant 1 in the second, fourth, and fifth convolutional layers as well as in the fully-connected hidden layers, and with the constant 0 in the remaining layers.
18. The learning rate was initialized at 0.01 and adjusted manually throughout training. The heuristic followed was to divide the learning rate by 10 when the validation error rate stopped improving, and it was reduced three times prior to termination.
19. The kernels on GPU 1 are largely color-agnostic, while the kernels on GPU 2 are largely color-specific.
20. Removing a single convolutional layer caused the network’s performance to degrade. Specifically, removing any of the middle layers resulted in a loss of about 2% for the top-1 performance of the network.
